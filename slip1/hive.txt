3. Solve the following using HIVE [10 Marks]
a. Create a database with the name Udetails.
    CREATE DATABASE Udetails;


b. Use the above-created database.
    USE Udetails;


c. Create a table UserData with fields (uid, name, age, gender, occupation, zipcode), where fields are terminated by comma.
CREATE TABLE UserData (uid INT,name STRING,age INT,gender STRING,occupation STRING,zipcode STRING)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ',';


d & e. Load data from local storage path /home/abc/data/UData.txt into the above table.
LOAD DATA LOCAL INPATH '/home/abc/data/UData.txt'
INTO TABLE UserData;


f. Find the number of users for each age.
SELECT age, COUNT(*) AS total_users
FROM UserData
GROUP BY age;


g. Add a column email_id to the above table.
ALTER TABLE UserData
ADD COLUMNS (email_id STRING);
